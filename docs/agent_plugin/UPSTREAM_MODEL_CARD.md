# 模型卡与实际训练记录

版本：AFDX synthetic ML 1.0。日期：2026-10-15 UTC。三个模型均在CPU上实际拟合，从输入数据生成树结构与节点权重，不使用预训练模型。

## 训练内容

| 模型 | 学习任务 | 实际配置 |
|---|---|---|
| diagnosis.json | 8类候选原因分类 | RandomForestClassifier，64树，最大深度9，最小叶样本4 |
| anomaly.json | 只学习正常行为，给出偏离分数 | IsolationForest，64树，每树最多256样本 |
| latency.json | 预测下一窗口p95时延的log1p | RandomForestRegressor，64树，最大深度9，最小叶样本5 |

权重及登记表总计1,864,007字节（1.778 MiB）。运行时使用NumPy读取普通JSON树，不依赖scikit-learn，不执行pickle/joblib对象。导出推理与原scikit-learn模型在全部1,600个验证窗口逐项比较，最大绝对差分别为分类2.22e-16、异常1.67e-16、回归log输出1.78e-15。

依赖版本：Python 3.12.14、NumPy 2.3.5、scikit-learn 1.8.0；完整依赖见requirements-train.txt。

## 数据与隔离

| 分区 | 窗口数 | 独立场景数 | 到达族 |
|---|---:|---:|---|
| train | 5120 | 512 | periodic, poisson, bursty |
| validation | 1600 | 160 | batched |
| test | 1920 | 192 | chirp, alternating |
| ood | 400 | 40 | chirp, alternating |

每场景10个相关窗口整组划分。训练/验证/测试场景ID及完整特征指纹无交集。未知复合故障仅出现在OOD分区。固定随机种子、数据CSV SHA-256和逐行预测均交付。

标签来自预先指定的故障注入原因；不是从预测结果回填。分类/异常模型使用18项测量特征，不使用标签、场景ID、窗口序号、split、流量族名称、网安原因码或未来时延。回归仅用七项负载特征，排除当前/未来时延。

到达、排队与近似处理耗时由abstract_shared_inspector_v1离散事件模型生成，四个100Mb/s字节流、每输入四帧槽；部分服务/错误统计按注入参数分布采样。它没有执行RTL，不是精确数字孪生，也没有校准到目标器件。模型学习的是这些合成假设；同一注入机制可能让某些类别容易分离。

**异常模型当前阈值漏报较多，保留为实验性排序/辅助信号，不能承担主要安全告警。** AUC较高不意味着当前阈值已达到高召回。阈值只用验证正常窗口的98分位选择，未根据测试结果反复调整。

分类主要混淆为正常与拥塞：240个正常测试窗口中39个被分到拥塞，240个拥塞窗口中22个被分到正常。其他六类在该合成集上可分性很强，这反映生成器假设，不能外推为真实环境100%识别。测试类频率均衡，实际部署正常流量占比、误报成本和故障先验不同。

时延区间以验证场景内10窗口最大log误差校准，名义目标为90%场景覆盖。留出场景实际覆盖仅77.08%，说明换到达族后未达到该目标；它不是90%保证，更不是时序上界。

## 未知复合故障

400个窗口只用于评测，包含训练中没有的双故障组合。模型拒绝/超支持范围比例20.25%；仍有79.75%输出一个已知候选原因。**当前开放集拒答不足，单原因结果可能漏掉第二种故障。** 即使高投票份额也不确认为根因；需要证据工具或后续多标签训练。

## 工程验证

29项测试通过，覆盖真实模型推理、JSON导出对照、缺失/非有限/越界测量、错误工作模式、标签特征拒绝、模型篡改、循环树拒绝、无训练库CPU推理、计数器回绕与复位边界、原事件ABI及实际双网帧CRC/差异。

隔离复现实际执行34.85秒，重新生成四份CSV、训练三个模型、评测、运行全部测试和三个CLI演示；四份CSV和三个树权重均与交付文件逐字节一致。原核心559个文件及网安插件41个实现/测试/夹具文件在训练后哈希保持一致。

本机Python/NumPy逐窗口运行三个模型的p50约27.47毫秒、p95约31.71毫秒，仅是该执行环境的主机基准；不放在实时转发路径。

## 实际数据与下一步

包内158条原RTL事件及两份CRC合法的冲突帧只验证读取接口和证据工具，未参与训练，未据此计算分类准确率。现版不包含完整原始MAC到18指标的在线生产者，只有事件/计数器时会明确返回缺失项。

部署前需要：采集目标系统正常及故障数据、校验18项指标口径、评估类别先验及正常误报、做多标签/未知复合故障建模、重校告警阈值与预测区间，并完成真实设备验证。仅以合成数据训练不能证明目标系统的诊断精度、攻击检出率、工业级可靠性或认证符合性。
