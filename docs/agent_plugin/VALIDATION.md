## 复现

从ZIP解压后的AFDX_Agent_Plugin目录运行：

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/validate.py --out reports/my_reproduction --rtl required
python -m afdx_agent verify --run reports/release_agent_final_20261015/cases/congestion
```

Icarus不在PATH时，给validate.py传`--iverilog`、`--vvp`，必要时加`--ivl-base`。每次选择新的输出目录。归档中命令的绝对路径是本次执行记录；重跑使用本机路径。编译生成的.vvp文件不作为交付依赖，脚本从完整冻结源文件重新编译。哈希链可检测报告或工具结果改动，但无签名认证。

`scripts/generate_cases.py`为演示输入生成器：它读取冻结观测夹具、固定种子和参考证据，向空的cases目录生成十个案例。发布测试在临时根目录生成并逐字节对比全部案例文件，不覆盖交付案例。案例生成不是模型重新训练或独立准确率评估。

ZIP中的DELIVERY_SHA256.json覆盖随包文件。它与source_hashes.json各司其职：前者覆盖最终交付文件及证据，后者证明本次验证期间实现、模型和测试输入保持冻结。
