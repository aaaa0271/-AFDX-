## 可观测时延及资源

本次111个场景中，60个正常ENFORCE接收帧有可配对的原始到达/输出记录。首字节输入到首字节输出的观测延迟为82..8413周期，在12.5MHz模型下为6.56..673.04微秒。较大值含4096字节文件末块的迭代SHA等待。逐帧记录在 `observed_latency.csv`。这是本测试负载下的测量，不是任意并发/攻击条件的最坏上界或硬实时容量证明。

默认主要存储数组逻辑容量：四通道帧队列24576字节、A/B历史24576字节、冻结证据3072字节、文件区32768字节，合计84992字节；另有重放/当前帧、规则、授权、SHA及元数据。该值是源代码数组大小计算，不代表目标FPGA已映射到相同容量的BRAM，实际LUT/寄存器/BRAM及时序必须综合确认。

压力场景刻意超过默认引擎处理预算，观察到可计数的有限队列整帧丢弃及恢复；没有把“不会缓存失控”写成“任意负载都不丢包”。增加插件后，需按实际BAG、四通道流量与哈希停顿重新做准入和最坏时延分析。
