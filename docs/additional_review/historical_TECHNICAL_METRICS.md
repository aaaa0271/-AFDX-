# R1 技术指标

来源：`results/run_20261010_222628_350469/`，所有数据均来自 ModelSim 日志/独立字节审计，不是手填目标值。

- 时钟：12.5MHz，80ns/byte；每网络数字链路100Mbit/s。
- 四基本VL端口8192字节；新增十二个Sub-VL端口默认2048字节。排队深度2个完整消息；采样三物理槽。
- RX线速小帧和大帧的实测最大缓冲可用延迟：3520ns / 119840ns。
- RTC：独立HZ=100000，+20ppm，sync=21，max_error=4998ns。
- Sub-VL：4×4端口，生产MAC实测58物理帧、42逻辑线数据报，逐帧审计序号、共享BAG、SAP/UDP绑定和负载。
- 物理存储预算：TX 172032 bytes；RX 172416 bytes（含UDP头的声明缓冲）。这不是器件资源/时序证明。

测量点被区分为：帧起始/结束、完整消息缓冲可用、应用 payload 交付、RTC 逻辑参考误差。R1 不是所有合法参数和相位的全局最坏情况证明。
