# 工程运行与提交

提交目标是桌面 AFDX_SOURCE_20261026 文件夹。使用最终生成的ZIP，
解压后应直接看到同名文件夹，以及ARINC.epr、rtl、tb、host、docs、evidence等内容。
不要将ZIP文件放入工程目录再反复压缩。

1. 阅读根目录README_PACKAGE.md和本次核查报告。
2. 在ModelSim可用的电脑上，工程根目录执行：

       python -m pip install -r requirements.txt
       python -B -u scripts/run_all.py --hdl-only --workers 4

   完整联动还需gcc/g++。只运行新增加卸载用例：

       python -B -u scripts/run_all.py --hdl-only --workers 3 --tests tb_615a_roundtrip tb_615a_download_faults tb_615a_download_security

3. 加卸载详细流程、容量和选项限制见DOWNLOAD_615A.md。
   回传文件及SHA-256见evidence/review_20261103中的卸载审计。

4. 五类旧截图保留在docs/screenshots。它们属于历史版本。
   已附关键WLF，ModelSim打开后使用source执行evidence/INDEX.md所列入口。
   新增卸载请以本次实际运行记录为证据，勿将旧截图称为新增功能验证图。

5. eLinx目前报Error(292028)，本机许可证host id不匹配。
   此许可证与ModelSim相互独立；联系软件提供方按本机实际host id更新授权，
   再打开ARINC.epr，或执行：

       python -B -u scripts/run_all.py --elinx-only --elinx "实际quartus_map.exe路径"

   不要修改/伪造host id或借用旧日志宣称编译完成。
   EQ6HL130综合、布局布线及目标时序需要真实工具结果，现包不宣称完成。

6. 打包前先更新插件清单，再更新根清单，最后校验ZIP。
   report_tools/build_source_package.py要求工程外的新文件名，不删除源目录，
   也不覆盖已有ZIP。交付的校验记录给出了本次ZIP的SHA-256。
