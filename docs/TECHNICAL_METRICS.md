# 技术指标口径

链路模型为12.5MHz字节时钟、80ns/byte、每网络100Mbit/s；A/B冗余不应加成单流有效吞吐率。LMAX范围64至1518字节（含FCS，不含前导码与IFG）。原始日志分别记录帧、完整消息和应用交付观察点。

提交指标至少区分：配置上限、仿真实测值、带前提的数学包络。前两者不能相互替代，也不能把局部测量写成所有负载和相位下的保证。

最终回归中的 `tb_datagram_line_rate` 包含小/大帧线速接收情形；`tb_datagram_mac_joint` 包含四路8192字节消息与服务竞争；`tb_foundation_shared_stress` 则检验持续负载情形；`tb_contest_rtc_convergence` 使用独立逻辑参考时钟验证漂移和恢复；`tb_integration_multi_services` 验证多域包交付与时钟恢复。具体值从同次回归原始日志提取到最终交付摘要，不引用旧R1数字冒充本次测量。

`scripts/prove_worst_case_envelope.py` 的262144组BAG组合和1455个帧长检查仅证明声明的理想容量包络；其输出包含对旧延迟估计的反例。需要严格时延保证时还必须限定源到达/突发、消费停顿、分片/Sub-VL、外部跳数和处理服务曲线。板级电气和路由后时序不属于本次赛题纯仿真结果。
